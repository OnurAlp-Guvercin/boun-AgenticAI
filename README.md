# boun-AgenticAI

Homework assignments for the Agentic AI course at Boğaziçi University.

## Contents

| Folder | Topic |
|---|---|
| [HW1](HW1/AgenticAI_hw1.ipynb) | Reasoning, tool use and evaluation: compares zero-shot, four-shot, self-consistency and reflection prompting on GSM8K with Qwen2.5-0.5B-Instruct, adds a restricted AST-based calculator agent, and discusses a methodological flaw in Ferber et al.'s medical-agent simulation. |

## Running

Open the notebook in Jupyter or Google Colab and run the cells in order. A GPU is recommended for model inference.
